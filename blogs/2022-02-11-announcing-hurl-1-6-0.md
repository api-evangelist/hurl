Announcing Hurl 1.6.0 Feb. 11, 2022 The Hurl team is happy to announce a new version of Hurl, 1.6.0 . Hurl is a command line tool powered by curl , that runs HTTP requests defined in a simple plain text format: # Get home: GET https://example.org HTTP/1.1 200 [Captures] csrf_token: xpath "string(//meta[@name='_csrf_token']/@content)" # Do login!
